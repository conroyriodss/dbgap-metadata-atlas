# Licensing status: maintainer decision required

No project-wide license is assigned by this prepared package. The repository can be publicly
viewable without being open-source licensed; public visibility does not itself grant reuse rights.

Before publication, determine the applicable rights in the authored code/documentation and the
institutional release process. Do not infer that all material is a U.S. government work solely from
the maintainer's affiliation, or add a personal copyright claim without verifying ownership.
Choose an approved software/documentation license or applicable government-work notice and
record its scope. Preserve third-party notices. A license for project code does not relicense
upstream source metadata, ontologies, articles or figures.

The Colab publisher requires explicit acknowledgement that the public-release and licensing
position has been reviewed. It does not generate or apply an MIT, Apache, CC, or government-work
license automatically. Once determined, add LICENSE/NOTICE, update this file and CITATION.cff,
and commit that reviewed change. Until then, describe the project as public source, not open source.
